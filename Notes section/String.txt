

Programming Notes: Boolean Arrays & Strings

---

1. Boolean Array

Definition:
An array that stores true or false values. Useful for tracking conditions or flags.

Syntax:

boolean[] flags = new boolean[5]; // default false
boolean[] checks = {true, false, true}; // initialized

Example:

boolean[] isAvailable = {true, false, true};
for(int i = 0; i < isAvailable.length; i++) {
    System.out.println("Index " + i + ": " + isAvailable[i]);
}

Output:

Index 0: true
Index 1: false
Index 2: true

Notes:

Default value is false.

Used to track multiple conditions.



---

2. String

Definition:
A sequence of characters. Immutable (cannot change after creation).

Syntax:

String str = "Hello";

Common Operations

Operation	Syntax	Example	Output

Length	str.length()	"Hello".length()	5
Char at index	str.charAt(index)	"Hello".charAt(1)	'e'
Concatenate	str1 + str2	"Hello" + " World"	"Hello World"
Substring	str.substring(start,end)	"Hello".substring(0,4)	"Hell"
Equals	str.equals("text")	"Hello".equals("Hello")	true
Equals IgnoreCase	str.equalsIgnoreCase("text")	"Hello".equalsIgnoreCase("hello")	true
Replace	str.replace("old","new")	"Hello".replace("l","p")	"Heppo"
Contains	str.contains("text")	"Hello".contains("lo")	true
Split	str.split("delimiter")	"Hi Java".split(" ")	["Hi","Java"]


Example:

String text = "Java Programming";
System.out.println(text.length());           // 16
System.out.println(text.charAt(5));          // 'P'
System.out.println(text.substring(0,4));     // "Java"
System.out.println(text.replace("Java","C++")); // "C++ Programming"
System.out.println(text.contains("Programming")); // true


---

3. StringBuilder

Definition:
Mutable string class. Efficient for multiple modifications.

Syntax:

StringBuilder sb = new StringBuilder("Hello");

Common Operations

Operation	Syntax	Example	Output

Append	sb.append("text")	sb.append(" World")	"Hello World"
Insert	sb.insert(index,"text")	sb.insert(6,"Java ")	"Hello Java World"
Replace	sb.replace(start,end,"text")	sb.replace(6,10,"C++")	"Hello C++ World"
Delete	sb.delete(start,end)	sb.delete(6,10)	"Hello World"
Reverse	sb.reverse()	sb.reverse()	"dlroW olleH"
CharAt	sb.charAt(index)	sb.charAt(0)	'H'
Length	sb.length()	sb.length()	11


Example:

StringBuilder sb = new StringBuilder("Java");
sb.append(" Programming"); // "Java Programming"
sb.insert(5, "Language "); // "Java Language Programming"
sb.replace(5, 13, "Script"); // "Java Script Programming"
sb.delete(5, 12); // "Java Programming"
sb.reverse(); // "gnimmargorP avaJ"
System.out.println(sb);


---

4. Combined String Operations Example

String str = "Java Programming";

// Uppercase
String upper = str.toUpperCase(); // "JAVA PROGRAMMING"

// Substring
String lang = str.substring(0, 4); // "Java"

// Replace space with _
String noSpace = str.replace(" ", "_"); // "Java_Programming"

// Split words
String[] words = str.split(" "); // ["Java", "Programming"]

// Reverse using StringBuilder
String reversed = new StringBuilder(str).reverse().toString(); // "gnimmargorP avaJ"

// Print results
System.out.println(upper);
System.out.println(lang);
System.out.println(noSpace);
System.out.println(words[0] + ", " + words[1]);
System.out.println(reversed);

Output:

JAVA PROGRAMMING
Java
Java_Programming
Java, Programming
gnimmargorP avaJ


---

5. Quick Comparison Table: String vs StringBuilder

Feature	String	StringBuilder

Mutability	Immutable	Mutable
Efficiency	Slower for many changes	Faster for multiple modifications
Common Methods	length(), charAt(), substring(), equals(), replace()	append(), insert(), delete(), replace(), reverse()
Use Case	Few modifications	Many modifications or loops



---

6. Tips & Notes

1. Use Boolean arrays to track conditions or flags.


2. Use String for simple text or few modifications.


3. Use StringBuilder when modifying strings frequently.


4. Remember: Strings are immutable; StringBuilder is mutable.


5. Frequently used String operations: split(), replace(), substring(), toUpperCase(), toLowerCase().
