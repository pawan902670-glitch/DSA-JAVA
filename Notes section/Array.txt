📘 Arrays in DSA – Complete Notes (Why, What, How, Purpose)

These notes are written for strong DSA foundation. Every topic explains WHY it exists, WHAT it is, HOW it works, and WHERE it is used. Last section includes Power Map (mental model).


---

1️⃣ What is an Array?

✅ What

An array is a linear data structure that stores elements of the same data type in contiguous memory locations.

Example:

arr = [10, 20, 30, 40]

✅ Why

Fast access using index

Simple structure

Base of many complex data structures


✅ How

Each element has an index (0-based)

Address calculation:


address = base + index × size

✅ Purpose

Store multiple values

Perform fast read/write

Foundation of DSA problems

Used in most problems

🔹 2D Array (Matrix)

Faster


🔹 Dynamic Array

---

3️⃣ Array Operations

🔹 Access (O(1))

arr[i]

WHY fast? → Direct memory access

🔹 Traversal (O(n))

Visit every element

🔹 Insertion

End → O(1)

Middle → O(n) (shifting required)


🔹 Deletion

End → O(1)

Middle → O(n)



---

4️⃣ Time & Space Complexity (Must Know)

Operation	Time

Access	O(1)
Search (Linear)	O(n)
Insertion	O(n)
Deletion	O(n)


WHY IMPORTANT? → Interview + Optimization


---

5️⃣ Searching in Arrays

🔹 Linear Search

Works on any array

Time: O(n)


🔹 Binary Search

Array must be sorted

Time: O(log n)


WHY Binary Search is fast? → Divide array into halves


---

6️⃣ Sorting Algorithms (Array-based)

Algorithm	Time	Why Used

Bubble	O(n²)	Learning
Selection	O(n²)	Simplicity
Insertion	O(n²)	Nearly sorted
Merge	O(n log n)	Stable
Quick	O(n log n)	Fast



---

7️⃣ Prefix Sum

✅ What

Pre-calculate sums

✅ Why

To answer range queries fast

✅ How

prefix[i] = prefix[i-1] + arr[i]

✅ Purpose

Reduce time from O(n) → O(1)

8️⃣ Subarray Concepts ⭐

🔹 Subarray

Continuous elements


🔹 Total Subarrays

n(n+1)/2

🔹 Important Problems

Max Subarray Sum

Subarray with given sum



---

9️⃣ Kadane’s Algorithm

✅ What

Find max subarray sum

✅ Why

Brute force is too slow

✅ How

currentSum = max(arr[i], currentSum + arr[i])

✅ Purpose

Optimization (O(n))


---

🔟 Two Pointer Technique

✅ What

Use two indexes

✅ Why

Avoid nested loops

✅ Use Cases

Sorted arrays

Pair sum

Remove duplicates
